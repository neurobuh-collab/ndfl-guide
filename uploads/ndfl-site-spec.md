## 1. КОНЦЕПЦИЯ И TONE OF VOICE

### Главная идея
Сайт — это дружелюбный проводник. Не налоговый справочник, а живой гид, который берёт пользователя за руку и ведёт его от «я вообще не понимаю, что такое НДФЛ» до «я знаю, сколько именно денег мне должно государство».

### Tone of voice
- Говорим «ты» (не «Вы»)
- Короткие предложения. Без канцелярщины.
- Каждый шаг объясняем так, будто рядом умный друг-бухгалтер
- Страшные слова (НДФЛ, налоговая база, вычет) вводим постепенно, сразу расшифровывая
- Мотивирующие подзаголовки: «Это проще, чем кажется», «Давай разберёмся вместе»

### Навигационная механика «шагов»
- Каждая глава — это пронумерованный Шаг (① ② ③ ④ ⑤)
- На десктопе: фиксированный прогресс-бар слева (sticky sidebar) показывает, на каком шаге пользователь
- На мобильном: pill-индикатор «Шаг 2 из 5» вверху каждой секции
- Плавный scroll-spy: активный шаг подсвечивается в сайдбаре
- Кнопка «Перейти к калькулятору» видна всегда (sticky CTA)

```

```

### 2.5 Анимации и переходы

```
Базовый transition:  all 0.2s cubic-bezier(0.4, 0, 0.2, 1)
Появление секций:    opacity 0→1 + translateY(16px→0), 0.5s ease-out (IntersectionObserver)
Раскрытие деталей:   max-height 0→auto + opacity, 0.3s ease
Hover карточки:      translateY(-2px) + box-shadow усиление, 0.2s
CTA кнопка hover:    scale(1.02), filter brightness(1.05)
Калькулятор result:  число счётчик (countUp) 0.6s ease-out
Смена года:          fade-in результатов 0.25s
```

## 3. КОМПОНЕНТЫ

### Компонент: StepHeader
```
- Шаг-бейдж (синий круг с номером)
- Рядом: eyebrow label (11px, uppercase, success-600) = «ГЛАВА 1», «ГЛАВА 2» и т.д.
- Под ним: H2 (название главы)
- Под ним: deck (17px, neutral-600 — мотивирующее intro-предложение)
- Декоративная линия-разделитель слева от бейджа (gradient line)
```

### Компонент: InfoCard (карточка вида вычета)
```
Стекло glass-card, padding 24px
- Верх: иконка (emoji или SVG) 40×40 в кружке success-50
- H4 — название вычета
- Caption — кому подходит (за кого можно)
- Body — что входит (ключевые 3–5 пунктов)
- Divider
- Limit pill: «лимит 150 000 ₽» — glass-card--warning, inline
- Tip pill: «упрощённо через Т-Банк» — glass-card, success
- Expand «подробнее ▸» — раскрывает полный список условий
```

### Компонент: CaseCard (практика)
```
Стекло glass-card, padding 20px 24px
- Eyebrow: «Из практики»
- Title (H4 bold)
- Body text (история клиента)
- Result box: glass-card--success, «Вернули: X ₽»
- Warning box (если есть): glass-card--warning
```

### Компонент: SourceLink (карточки «где получить»)
```
Горизонтальная карточка:
- Иконка (emoji) в кружке 40×40
- H4 + Caption
- Теги каналов (pill)
- Ссылка «перейти →» — primary-500
- hover: translateY(-2px), border primary-200
```

### Компонент: YearSelector
```
4 кнопки: 2023 | 2024 | 2025 | 2026
Активная: background primary-500, text white, border none
Неактивная: glass-card, border neutral-200, text neutral-600
transition 0.2s
```

### Компонент: AmountInput
```
Крупный input (18px, tabular-nums)
Label над полем (13px, neutral-600)
Placeholder: «0 ₽»
Focus ring: 2px solid primary-400, border-radius 12px
Авто-форматирование: пробелы-разделители тысяч (1 000 000 ₽)
Limit hint под полем (11px, neutral-400)
Иконка ₽ справа внутри поля
```

### Компонент: ResultBox
```
glass-card--success, padding 24px
«К возврату» — label (13px, success-600, uppercase)
Сумма — 38px, 800 weight, success-900
Детализация под суммой — разбивка по категориям (compact grid 2×2)
Предупреждение (если расчётная > уплаченной) — glass-card--warning
Блок «что переносится / что сгорает» — colored strips
```

### Компонент: ProgressSidebar (десктоп)
```
Фиксированный (sticky) вертикальный список слева на viewport
Элементы: ● (кружок) + название главы
Активный: primary-500 кружок + primary-500 текст + вертикальная линия
Прошедшие: success-500 кружок + neutral-400 текст
Будущие: neutral-200 кружок + neutral-300 текст
Виден только на viewport ≥ 1100px
```

## 5. ФОРМУЛЫ КАЛЬКУЛЯТОРА (полные, по годам)

### Расчёт НДФЛ

**2023–2024 (двухступенчатая шкала):**
```
getTax(a):
  если a ≤ 0:             return 0
  если a ≤ 5 000 000:     return a × 0.13
  иначе:                  return 650 000 + (a − 5 000 000) × 0.15
```

**2025–2026 (пятиступенчатая шкала):**
```
getTax(a):
  если a ≤ 0:              return 0
  если a ≤ 2 400 000:      return a × 0.13
  если a ≤ 5 000 000:      return 312 000 + (a − 2 400 000) × 0.15
  если a ≤ 20 000 000:     return 702 000 + (a − 5 000 000) × 0.18
  если a ≤ 50 000 000:     return 3 402 000 + (a − 20 000 000) × 0.20
  иначе:                   return 9 402 000 + (a − 50 000 000) × 0.22
```

**Ставка по доходу (getRate):**
```
2025+:
  a ≤ 2 400 000   → 13%
  a ≤ 5 000 000   → 15%
  a ≤ 20 000 000  → 18%
  a ≤ 50 000 000  → 20%
  иначе           → 22%

2023–2024:
  a ≤ 5 000 000   → 13%
  иначе           → 15%
```

### Расчёт вычетов с лимитами

```
socLim  = год ≥ 2024 ? 150 000 : 120 000
cLim    = год ≥ 2024 ? 110 000 : 50 000

socRaw  = медицина + лекарства + обучение/курсы + спорт + обучение_детей_общий
dS      = min(socRaw, socLim) + дорогостоящее_лечение
dC      = сумма по каждому ребёнку: min(сумма_реб, cLim)
dI      = min(ИИС, 400 000)
dP      = min(покупка_жилья, 2 000 000) + min(проценты_ипотека, 3 000 000)
```

### Алгоритм расчёта (порядок приоритетов)

```
base = income

// 1. ИИС (не переносится)
rI = getTax(base) − getTax(max(0, base − dI))
iisUsed = min(dI, base)
base = max(0, base − dI)

// 2. Социальные + дорогостоящее (не переносятся)
rS = getTax(base) − getTax(max(0, base − dS))
socUsed = min(dS, base)
base = max(0, base − dS)

// 3. Обучение детей (не переносится)
rC = getTax(base) − getTax(max(0, base − dC))
chUsed = min(dC, base)
base = max(0, base − dC)

// 4. Имущественный (переносится)
rP = getTax(base) − getTax(max(0, base − dP))
propUsed = min(dP, base)
propCarry = dP − propUsed  // переносится на следующий год

total = min(rP + rS + rC + rI, getTax(income))
```

### Логика предупреждений

```
propCarry > 0:
  → «Имущественный вычет: использовано X в {год}. Остаток X переносится на {год+1}.»

dI > iisUsed:
  → «ИИС: неиспользованные X сгорают, не переносятся.»

socRaw > socLim:
  → «Социальные расходы превышают лимит X ₽. Лишние X сгорают.
     Второй супруг тоже может заявить свой лимит.»

dS > socUsed (и socExcess = 0):
  → «Социальные расходы использованы частично — не хватает НДФЛ.
     Неиспользованные X сгорают.»

childrenRaw > childrenCapped:
  → «Обучение детей превышает лимит X ₽ на ребёнка. Лишние X сгорают.»

dC > chUsed:
  → «Обучение детей: вычет X использован частично — не хватает НДФЛ.
     Неиспользованные X сгорают.»
```
